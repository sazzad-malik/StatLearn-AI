# StatLearn AI – Prototype

Clean demo for SIH problem statement on AI-enabled competency gap analysis + personalized training + quiz generation for Official Statistical System.

## Features
- Role-based skill assessment (JSO, SO, SSO, etc.)
- AI-style competency gap analysis with severity
- Personalized course recommendations (iGOT-style mock)
- MCQ / Quiz generator from learning material
- Learner dashboard with progress path

## No personal data
Prototype is generic — no team name, college, or individual names.
